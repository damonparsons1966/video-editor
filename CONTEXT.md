# Title: Video Editor

## Description

This is a basic and simple to use light weight video editor. The user can select or drag and drop a video file in popular formats into the app to perform some basic editing fucntions on it, the save the updated video.

The initial functions are:

- Adjust the playback speed by small 0.1 increments (faster and slower) from -2.0 to +2.0
- Trim the start and end of the Video
- Remove and replace the audio track
- Playback
- Save the new version of the video 

We will add functionality and additional device support (android for example) over time in future versions.

The core requirement is this is light-weight. Most downloadable editors can perfrom complex editing but are difficult to use and resource instensive requiring modern hardware. This will run on an old 5 - 6 year old laptop.

## Device Support
Windows Laptop/Desktop running Windows 10 and above
