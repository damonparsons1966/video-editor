# Title: Video Editor

## Description

This is a basic and simple to use light weight video editor. The user can select or drag and drop a video file in popular formats into the app to perform basic editing functions, then save the updated video.

The initial functions are:

- Adjust playback speed from −2.0× to +2.0× in 0.1× steps. Negative values reverse the trimmed video and any kept source audio. Replacement audio and overlays play forward. At 0.0×, playback pauses and export is disabled.
- Trim the start and end of the Video
- Remove and replace the audio track
- Playback
- Save the new version of the video 

The core requirement is this is light-weight. Most downloadable editors can perfrom complex editing but are difficult to use and resource instensive requiring modern hardware. This will run on an old 5 - 6 year old laptop.

## Device Support
Ubuntu desktop and laptop. The current target is Ubuntu 26.04 LTS on x86-64, distributed as a Debian package.
